## Крупные задачи по системам (MVP)

### **АБС / модуль ставок (Т1)**
  * Согласовать контракт по API (T1.1)
  * Доработка и настройка модуля депозитных ставок как единого источника истины. (Т1.2)

### **DepositRateService (Т2)**
  * Согласовать контракт по API (T2.1)
  * Реализация API и кеша ставок и синхронизации с АБС. (Т2.2)
  * Генерация файла ставок (CSV/XLSX) + сжатие + шифрование/пароль. (Т2.3)
  * Автоматическая отправка зашифрованного архива ставки партнёру по e-mail. (Т2.4)

### **Система внутреннего колл-центра (Т3)**
  * Согласовать контракт по API (T3.1)
  * Интеграция с DepositRateService через API, вывод ставок операторам. (Т3.2)
  * Фронтенд для внутренней системы. (Т3.3)

### **Система партнёрского колл-центра (Т4)**
  * Согласовать контракт по формату файла (T4.1)
  * Автоматическая загрузка и расшифровка файла (если делают у себя) либо ручная загрузка оператором. (Т4.2)
  * Обновление ставок в системе. (Т4.3)

### **Интеграция / коммуникации / поддержка (Т5)**
  * Настройка защищённой отправки e-mail (SPF/DKIM/DMARC, доменные правила).  (Т5.1)
  * Настройка формата архива: ZIP/AES + пароль, единый стандарт.  (Т5.2)
  * Мониторинг отправки писем, ошибок доставки, логов формирования файлов.  (Т5.3)
  * Регламенты обработки инцидентов (файл не дошёл, пароль неверный, файл не открылся).  (Т5.4)

## В рамках года

  * Переделать обмен файлами, например через ЭДО с шифрованием на КЭП.
  * Внедрить Кафку, и сервисы, для обновления ставок в системах и генерации файлов.
